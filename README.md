## How Each Project Is Organized

```
project_folder/
├── README.md           ← description, I/O list, how to run
├── siemens_software/   ← full project archive (.zip / .zapXX)
├── source/             ← readable text exports (STL/SCL, symbols, hardware config)
└── factory_io/         ← Factory I/O scene, screenshots, demo video
```

The `source/` folder lets you read the PLC code directly on GitHub without installing Siemens software.
